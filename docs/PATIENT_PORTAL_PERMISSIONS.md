# Permisos del portal del paciente

El paciente puede consultar su perfil, editar campos de contacto permitidos, cambiar su contrasena, gestionar citas dentro de la politica y consultar historial, recetas, ordenes, documentos, facturas o pagos cuando la clinica los habilita.

No puede seleccionar otro paciente o clinica, editar identidad clinica, crear diagnosticos, modificar recetas u ordenes, ver notas internas, consultar auditoria ni usar endpoints del personal.

La API aplica los permisos aunque el frontend sea manipulado. Web y movil tambien ocultan accesos deshabilitados para evitar flujos sin salida.
